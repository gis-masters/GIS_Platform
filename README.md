## 🛠 Системные требования

- **Оперативная память**: 64 GB

## 📋 Инстукция по применению

**Установка**

1. Запустите скрипт для быстрого старта
2. Укажите папку расположения данных (или используйте расположение по умолчанию)
3. Укажите логин админстратора
4. Укажите пароль администратора (или сгенерируйте автоматически)
5. Дождитесь установки приложения
6. После окончания установки будет выведен отчет об установке с доступами на ключевые компоненты

**Обновление**
1. Запустите скрипт для быстрого старта
2. Дождитесь установки приложения
3. После окончания установки будет выведен отчет об установке с доступами на ключевые компоненты
