### Генерация типов для фронта

Для этого проекта и только из этого пакета `generated` настроена генерация типов для фронтенда.

Основной результирующий файл:
`portal-ui/src/server-types/common-contracts.d.ts`

Отдельно генерируется инфраструктурный файл для `JsonNode`:
`portal-ui/src/server-types/jackson-types.d.ts`

`common-contracts.d.ts` должен ссылаться на него импортом, чтобы системный jackson-тип не разрастался внутри общего файла контрактов.

Настроено в `pom` проекта, пример запуска в скрипте: `scripts/build-and-copy-generated-types.sh`

Собственно этот скрипт и нужно запускать для генерации при внесении изменений в этих контрактах.

```
После копирования скрипт форматирует все сгенерированные `.d.ts` через prettier, поэтому файлы в `portal-ui/src/server-types`
сразу должны быть в пригодном для фронта виде.
```
