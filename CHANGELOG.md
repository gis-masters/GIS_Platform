## 2026-06-17
###### _[3685ef212b157ee085bd73cfb7a2106afece0962]_

### Список изменений
- Инсталлятор картографической платформы теперь гибко (в процентах) распределяет ресурсы между контейнерами в зависимости от объема доступной оперативной памяти
- Создание новых пользовательских моделей данных теперь выполняется проще с применением визуального UI для формы шаблонов схем

## 2026-06-11
###### _[b421bac87516c4191569cd4d65f67e6dda3d4ed9]_

### Список изменений
- Обновлены стили для отображения данных территориального планирования
- Расширена линейка масштабов печати
- Увеличена скорость  отображения  данных  функционального зонирования ФГИС ТП
- Добавлены схемы и стили зонирования правил землепользования и застройки в соответствии требованиями стандартов приказа 10
- Информация  о "Природных территориях" из файлов xml КПТ теперь распаковывается в отдельный слой
- Исправлена проблема именования файлов при сохранении картографических отчетов
- Персональные шаблоны отчетных форм теперь доступны только в рамках "своей" организации
- Переработана визуализация и подправлена системная схема данных для "Зон с особыми условиями" кадастрового плана территории
- Локализация шаблонов отчетных форм теперь задается как переменная в файле настроек
- Реализован адресный поиск на карте с применением API НСПД
- Исправлены типы данных в схемах кадастрового плана территорий
- Увеличен лимит размера шаблона отчетов до 51 Мб

## 2026-05-04
###### _[9d68b46acd4f6fde1b72d09a80cf5b63451e8a9b]_

### Список изменений
- В общий код приложения добавлены два сервиса: поддержки ЭЦП (crypt-service) и сервис нотификаций (notification-service)
- Добавлена возможность указывать шаблоны отчетов в схеме данных для формирования  пользовательской настраиваемой выписки об объекте
- Информация о территориальных зонах ПЗЗ для данных кадастровго плана территории убрана из таблиц ЗОУИТ и теперь распаковывается в векторную таблицу "Территориальные зоны"
- Шаблоны схем данных теперь доступны к просмотру непривилегированному пользователю в разделе "Шаблоны схем"
- Дата предоставления кадастровых сведений Росреестра, теперь автоматически заполняется из XML в карточке документа при импорте данных кадастрового плата территории
- Расширено API управления картографическими подосновами в проекте
- Исправлено зависание геосервера для стилей с svg файлами после обновления платформы

## 2026-04-08
###### _[6f408633c2534dace1e12c583939de13c71a4cce]_

### Список изменений
- Технологический стек платформы обновлён до Java 25 и актуальной версии Spring Framework
- При печати "Выписки об объекте", изображение объекта автоматически позиционируется и масштабируется по центру рамки печати
- Блок импорта и экспорта данных теперь размещены на верхней панели проекта
- При первичной установке картографической платформы можно указывать путь для хранения данных

## 2026-03-20
###### _[a38cb977d449a0b6c82555da235223612f440aad]_

### Список изменений
- Добавлена возможность формирования отчета "Выписка об объекте" в формате Word. Печать "Выписки об объекте" переведена на универсальную инфраструктуру шаблонов.

## 2026-03-06
###### _[1e38227dcfa8714e3e58bcbb3a4f20d56c5666d7]_

### Список изменений
- Исправлено создание специализации "Инвентаризация и таксация зеленых насаждений"
- Исправлено создание специализации "Территориальное планирование"
- Добавлены изменения в стили и схемы данных территориального планирования
- Исправлена работа с изображениями при формировании отчетной формы
- Добавлена возможность загрузки растровых данных из GPKG
- Обновлены и исправлены схемы данных для территориального планирования
- Добавлена возможность выгрузки векторных таблиц из проекта в OGC GeoPackage
- Удалены неактуальные схемы данных территориального планирования приказа 10
- Кнопка "регистрации новой специализированно организации" теперь включена по умолчанию  для картографической платформы при развертывании новом сервере
- Исправлено отображение некорректных значений для атрибутов типа «Choice» (выпадающий список).
- Исправлена ошибка получения внешних слоев из НСПД
- В картографическую платформу (отдельным контейнером) интегрирован бесплатный инструмент для автоматической генерации отчетных документов (PDF, DOCX, XLSX, PPTX и др.) из JSON данных с использованием шаблонов
