## 2026-03-06
###### _[1e38227dcfa8714e3e58bcbb3a4f20d56c5666d7]_

### Список изменений
- Исправлено создание специализации "Инвентаризация и таксация зеленых насаждений"
- Исправлено создание специализации "Территориальное планирование"
- Добавлены изменения в стили и схемы данных территориального планирования
- Исправлена работа с изображениями при формировании отчетной формы
- Добавлена возможность загрузки растровых данных из GPKG
- Обновлены и исправлены схемы данных для территориального планирования
- Добавлена возможность выгрузки векторных таблиц из проекта в OGC GeoPackage
- Удалены неактуальные схемы данных территориального планирования приказа 10
- Кнопка "регистрации новой специализированно организации" теперь включена по умолчанию  для картографической платформы при развертывании новом сервере
- Исправлено отображение некорректных значений для атрибутов типа «Choice» (выпадающий список).
- Исправлена ошибка получения внешних слоев из НСПД
- В картографическую платформу (отдельным контейнером) интегрирован бесплатный инструмент для автоматической генерации отчетных документов (PDF, DOCX, XLSX, PPTX и др.) из JSON данных с использованием шаблонов

## 2025-11-27
###### _[cc02dd0efbcc6cd461c430cb71cf30ee74df0c5f]_

### Список изменений:
- Добавлена новая специализация "Контроль размещения рекламных конструкций"
- Исправлена проблема публикации документов в проект в папке
- Область карты для проектов теперь можно задать через интерфейс визуальный карты
- При импорте строковых данных GML в таблицы с жёстким лимитом символов выполняется обрезка содержимого
- Исправлена проблема удаления из карточки документа опубликованных файлов
- Реализована возможность импорта ZIP-архивов с SHP-файлами, имеющими нестандартные имена.
- Устранена проблема со скроллингом в выпадающем меню при работе с документами
- Импорт GML по XSD схеме приказа 10 способен загружать очень длинные строки
