Проверка может быть проведена как для нескольких, так и для всех слоёв проекта.

Для выполнения проверки данных на соответствие Приказу, необходимо:

  1. Нажать на иконку «Проверка ошибок по Приказу».
  2. В появившейся форме нажать «Проверка данных».
  3. Выбрать слои для проверки.
  4. Выполнить проверку, нажав «Проверить»
