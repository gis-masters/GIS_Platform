Вызов атрибутивной таблицы объектов слоя рассмотрен в п.3.1.

После чего для удобства поиска в таблице по объектам рекомендуется воспользоваться фильтром, для этого:

  1. Для этого требуется кликнуть на кнопку «Фильтр».
  2. Выбрать нужное поле для поиска из имеющихся.
  3. Ввести необходимые данные в поле.
  4. Поиск двух и более слов следует вводить через знак «%».
