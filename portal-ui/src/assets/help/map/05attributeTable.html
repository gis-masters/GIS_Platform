Атрибутивная таблица содержит список объектов слоя

  1. Для фильтрации объектов в таблице требуется кликнуть на кнопку «Фильтр».
  2. Выберите поле для фильтрации объектов в таблице.
  3. Введите необходимые данные в поле(на карте и в таблице будут отображены только отфильтрованные данные)
  4. Используйте подстановочный символ «%»(соответствует любой строке) для расширенной фильтрации.
