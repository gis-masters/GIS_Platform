Реестр документов предназначен для систематизированного просмотра параметров данных в выбранной библиотеке документов.

Открытие реестра (1)

  • Экспортировать реестр(2) — выгружает информацию документов отобранных в реестре в файл формата csv, xlsx.
  • Настройка столбцов(3) — вызывает диалоговое окно выбора видимых столбцов
  • Меню управления документом(4) — появляются при наведении курсора на строку в таблице, вызывает меню управления документам.
