Информации об объекте

Информация об объекте отображается в отдельной панели и включает атрибутивные данные, координаты и связанные документы.

Просмотр информации об объекте

  1. Кликните ЛКМ по объекту на карте.
  2. В правой части окна откроется панель с объектами (1), расположенными в точке клика.
  3. Для открытия дополнительной информации об объекте нажмите (2).
  4. Для отображения объекта в центре карты нажмите (3).
  5. Для снятия выделения с объекта нажмите (4).

Дополнительная информация об объекте

  1. Панель содержит атрибутивную информацию (1) и координатное описание объекта (2).

Кнопка (3) позволяет выбрать проект для отображения объекта на карте.

Связанные документы

  1. Если к объекту прикреплены Ссылки на документы (1), они отображаются в панели.
  2. При нажатии ЛКМ по ссылке (1) откроется окно с информацией (2).
