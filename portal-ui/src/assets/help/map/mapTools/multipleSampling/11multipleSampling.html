Выбор объектов

Режим позволяет выделять рамкой видимые векторные объекты на карте.

  1. Нажмите кнопку Выбор объектов (1).

    2. Курсор изменит вид (2), активировав режим выделения рамкой.

  2. Выделите объекты, обведя их рамкой ЛКМ.
  3. Для добавления объектов к выделению удерживайте клавишу Shift и используйте ЛКМ.
  4. Для снятия выделения с объектов удерживайте клавишу Ctrl и используйте ЛКМ.
  5. Максимальное количество одновременно выделенных объектов — 100.
  6. В режиме выделения перетаскивание карты выполняйте средней кнопкой мыши.
  7. Снимите выделение, щелкнув ЛКМ по свободной области карты или дважды нажав клавишу Esc.
