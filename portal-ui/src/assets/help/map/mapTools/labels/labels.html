Аннотация — это функция, которая позволяет добавлять текстовую информацию или пометки на карте.

Для работы с аннотацией требуется: на верхней панели инструментов нажать на кнопку (1) Показать/скрыть аннотации.

После включения аннотаций появится список функций:

  • Добавить аннотацию (2) — позволяет отметить точку на карте где должна находится аннотация и ввести текст.
  • Вспомогательная линия (3) — позволяет добавить вспомогательные линии к аннотациям, чтобы обозначить связь с другими объектами на карте.
  • Удалить все аннотации (4) — позволяет удалить все созданные аннотации с карты.
  • Добавить поворотные точки (5) — позволяет добавить поворотные точки одного объекта на карту.

Аннотация видна пользователю в браузере на том компьютере, где она создается и под данной учетной записью, и может использоваться для печати фрагмента карты.
