Для поиска объекта по адресу, следует указать в окно поиска (1) адрес в формате «Город, улица, номер дома» (Симферополь, Ленина 58), для начала поиска нажать «Enter» или значок «Лупа » (2). Далее Вам будет предложен список найденных адресов (3), для перехода к нужной точке, требуется нажать (4). После этого ваша точка на карте будет обозначена значком (5).
