Для распечатки фрагмента карты требуется:

  1. На верхней панели кликнуть ЛКМ на значок(1) «Печать».
  2. В окне предварительного просмотра печати разместите изображение карты посредством перетаскивания карты(2) Укажите требуемые параметры печати, а затем нажмите на кнопку «Печать»(3) скачивается файл pdf. Для скачивания файла jpg нажмите кнопку «Экспорт в JPG»
