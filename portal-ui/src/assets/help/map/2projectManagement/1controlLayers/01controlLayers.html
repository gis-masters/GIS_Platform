Управление слоями

Панель слева отображает список всех слоев, доступных в текущем проекте. Через нее выполняется включение, отключение, настройка прозрачности, просмотр легенды, открытие атрибутивной таблицы, импорт данных и переход к слою.

Отображение и скрытие слоя

  1. Чтобы скрыть слой, нажмите значок Видимый глаз (1).
  2. Чтобы отобразить слой, нажмите значок Перечеркнутый глаз (2). Слой появится на карте.

Настройка прозрачности слоя

По умолчанию прозрачность слоя установлена на 70%. Для изменения прозрачности выполните:

  1. Откройте дополнительное меню слоя .
  2. Перетащите ползунок для изменения прозрачности.

Отображение легенды слоя

  1. Нажмите значок Стрелка (1).
  2. Под слоем отобразится легенда с обозначениями (2).
  3. Для показа всех знаков легенды, а не только тех что сейчас на карте нажмите (3.)

Открытие таблицы атрибутов

  1. Откройте дополнительное меню нужного слоя .
  2. Выберите Открыть таблицу атрибутов (2).
  3. Таблица с атрибутивной информацией отобразится в отдельном окне.

Импорт данных в слой

  1. Откройте дополнительное меню слоя (1) и нажмите кнопку Импорт (2).
  2. Выберите файл XML (межевой план) или SHP (геометрия) (3).
  3. Нажмите Импортировать (4). Данные появятся на последней странице атрибутивной таблицы.

Переход к слою

  1. Включите нужный слой.
  2. Откройте его дополнительное меню (1).
  3. Нажмите Перейти к слою (2).

Карта отобразит весь слой в масштабе, оптимальном для его просмотра.
