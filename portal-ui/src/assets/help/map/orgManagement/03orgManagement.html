Управление организацией

Настройки организации и очистка

Вкладка «Настройка организацции» предназначена для ограничения одновременно всех пользователй и групп пользователей. Снятое выделение опередлённой функции заблокирует возможно использовать её у всех, кроме создателя организации. Чтобы изменения вступили в силу используйте кнопку «Сохранить»

Вкладка «Очистка» содерожит в себе функцию «Очистить дефолтные слои». Данная функция очищает ненужные файлы на «Geoserver», которые создаются при неудачном импорте «.shp» файлов.
