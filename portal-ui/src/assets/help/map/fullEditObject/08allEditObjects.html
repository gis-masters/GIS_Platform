Множественное редактирование позволяет одновременное заполнение одинаковых атрибутов у некоторого количества объектов.

Для множественного редактирования объектов через атрибутивную таблицу следует:

  1. Открыть атрибутивную таблицу слоя (п.4.2).
  2. Выделить галочками нужные объекты.
  3. Кликнуть на кнопку «Правка».
  4. В выпадающем меню выбрать «Множественное редактирование».
  5. В появившейся панели заполнить требуемую атрибутивную информацию.
  6. Нажать «Сохранить».

Для множественного удаления объектов через атрибутивную таблицу следует:

  1. Открыть атрибутивную таблицу слоя (п.4.2).
  2. Выделить галочками нужные объекты.
  3. Кликнуть на кнопку «Правка».
  4. В выпадающем меню выбрать «Удалить».
