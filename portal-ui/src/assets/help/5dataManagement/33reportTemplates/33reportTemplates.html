Шаблоны отчётов

Шаблоны отчётов — это раздел для хранения и применения печатных форм к данным определённой схемы.

Шаблон позволяет сформировать специальный отчёт для выбранного вида данных, например для ГПЗУ или земельного участка.

Переход к разделу

Откройте раздел «Управление данными».

Выберите пункт «Шаблоны отчётов» (1).

Инструменты и элементы управления

  • Список шаблонов — область для выбора шаблона отчёта.
  • Карточка шаблона — область для просмотра названия, идентификатора, автора и даты создания.
  • Скачать — кнопка для загрузки файла шаблона отчёта.
  • Удалить — кнопка для удаления выбранного шаблона. Доступна пользователю с правами администратора.
  • Добавить — кнопка для загрузки нового шаблона отчёта. Доступна пользователю с правами администратора.
  • Фильтр — поле для поиска шаблона в списке.
  • Сортировка — настройка порядка отображения шаблонов.

Просмотр и скачивание шаблона отчёта

Для просмотра информации о шаблоне отчёта:

  • Откройте раздел «Шаблоны отчётов».
  • Выберите шаблон в списке.
  • Проверьте информацию в карточке шаблона.
  • Нажмите кнопку «Скачать», чтобы загрузить файл шаблона.

В результате файл шаблона будет сохранён на устройство и станет доступен для просмотра или передачи.

Привязка шаблона отчёта к схеме

Чтобы использовать шаблон при печати отчёта, добавьте идентификатор шаблона в нужную схему.

Для выбора схемы:

  • Откройте раздел «Управление данными».
  • Выберите пункт «Шаблоны схем».
  • Найдите нужную схему с помощью фильтра.
  • Выберите схему в списке.

Для редактирования схемы в интерфейсе:

  • Нажмите кнопку «Редактировать» в карточке схемы.
  • Проверьте основные параметры схемы.
  • При необходимости измените свойства схемы.
  • Нажмите «Сохранить».

Для добавления имени шаблона через JSON:

  • Нажмите «Редактировать в JSON».
  • Найдите параметр printTemplates.
  • Добавьте идентификатор нужного шаблона отчёта.
  • Нажмите «Сохранить».

Печать отчёта по шаблону

После добавления шаблона в схему отчёт становится доступен в интерфейсе карты для объектов этой схемы.

Для печати отчёта:

  • Откройте карту.
  • Выберите объект нужной схемы.
  • Откройте печать или формирование отчёта.
  • Выберите добавленный шаблон отчёта.
  • Запустите формирование отчёта.

В результате система сформирует отчёт по выбранному объекту с использованием заданного шаблона.

Права доступа

  • Администратор может просматривать, добавлять, скачивать и удалять шаблоны отчётов.
  • Пользователь без прав администратора может просматривать и скачивать доступные шаблоны, если такие права предоставлены.
  • Пункт «Шаблоны отчётов» отображается в управлении данными только при включённой настройке раздела.
