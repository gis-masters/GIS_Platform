Для авторизации в геоинформационной системе Вам, требуется логин и пароль выданной Вам учетной записи на портале.

Для входа в учётную запись на портале, требуется:

  1. Запустить приложение через браузер, для этого требуется ввести интернет-адрес геоинформационной системы в адресной строке браузера.
  2. Нажать кнопку «Войти», для отображения полей ввода учётных данных.
  3. Ввести логин от учётной записи в поле «E-mail».
  4. Ввести пароль от учётной записи в поле «Пароль».
  5. Нажать кнопку «Войти» синего цвета.
