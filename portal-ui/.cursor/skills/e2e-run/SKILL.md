# Запуск e2e (portal-ui)

Корень проекта: `portal-ui`.

## Запрет для агента: `test:e2e:devLocal`

- **Не запускать** `npm run test:e2e:devLocal` и **не подставлять** его как запасной вариант, если `test:e2e:dev` без грида или сети не сработал.
- При фразах вроде "запусти тесты", "прогони e2e", "точечно --spec" использовать **`test:e2e:dev`** (см. ниже). Исключение: пользователь **явно** просит devLocal (слово `devLocal` или прямой эквивалент: Chrome на этой машине, без грида, localhost для wdio).
- Если без инфраструктуры прогон невозможен: сообщить пользователю предусловия (`ng serve`, офисная сеть для грида), а **не** молча переключаться на devLocal.

## Предусловия

Выполняет **пользователь**: поднят **`ng serve`**. Для **`test:e2e:dev`** ещё: доступ к **офисной сети**, чтобы удалённый Selenium Grid достучался до машины с приложением (браузер на гриде не открывает `localhost` на вашем ПК).

## Основной режим: `test:e2e:dev`

```bash
npm run test:e2e:dev
```

- Конфиг: `tests/_harness/config/wdio.e2e.dev.conf.ts`.
- `baseUrl`: `http://<офисный-IP>:4200`, IP — `getMyOfficeIp()` в `tests/_harness/config/getMyOfficeIp.ts`. Грид открывает **ваш** хост в офисе, не loopback.

**`test:e2e:devLocal`**: только по **прямой** просьбе пользователя; см. раздел "Запрет для агента" выше.

**Один файл или один сценарий** — `--spec`; после `:` — **номер строки**, где в `.feature` стоит `Scenario:` или `Scenario Outline:` (не заголовок на другой строке, не шаг из Background):

```bash
npm run test:e2e:dev -- --spec tests/e2e/dataManagement/documentCreateChild.feature:14
```

Проверка: в логе должны идти ожидаемые шаги. Если с `:N` прогон "пустой" или не тот сценарий — номер строки неверен.

Другие флаги WDIO/Cucumber — по необходимости (в т.ч. `--cucumberOpts.tags=`).

## `test:e2e` (как у CI)

Использовать **только если пользователь явно просит**. Удалённый грид; при необходимости `baseUrl` на конкретный стенд — **только по явной просьбе** (не подставлять стенд самостоятельно).

Тестовые стенды обычно в подсети **`10.10.10.*`**. Если просят прогнать на **131** (имеют в виду только последний октет), это **`10.10.10.131`**.

```bash
npm run test:e2e -- --spec tests/e2e/dataManagement/documentCreateChild.feature --baseUrl http://10.10.10.131
```

## Визуальные эталоны

Чтобы обновить эталонный скриншот визуального теста: удалить соответствующий файл эталона и снова прогнать тест. **Агент не удаляет эталоны и не перегенерирует их без явной команды пользователя.**

## После падения

Скриншоты ошибок и временные файлы: `tests/_screens/.tmp/` (см. также [e2e-mcp](../e2e-mcp/SKILL.md) — логины, harness, отладка через Playwright MCP).

## Связь с e2e-mcp

- **e2e-run** — запуск тестов в терминале.
- **e2e-mcp** — повторение шагов сценария в браузере через Playwright MCP, чтобы увидеть поведение UI без полной отладки только по логам.
