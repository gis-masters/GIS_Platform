##### Менеджер проекта
- [ ] Acceptance Criteria проверены и утверждены
- [ ] WorkItems (Bugs\PBI) привязаны к parent Feature в Backlog

##### Тестировщик
- [ ] Все задачи на эксплораторное тестирование закрыты
