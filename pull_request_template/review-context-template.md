# Review Context

Нормально работает только если коммитов и файлов в низ до 10.
Редактировать код в процессе ревью крайне не желательно.

Как пользоваться:
Заполни и сохрани этот файл как `.review-context.md` в текущей директории репозитория перед self-review.
Файл локальный и по умолчанию игнорируется git.
Обязателен только блок `Зачем сделана задача`.
Пустые и неактуальные секции можно удалять целиком.

Конкретная команда запуска агента:
Запусти scripts/self-review.sh и проведи code review итогового diff ветки.
Учитывай pull_request_template/.review-context.md
Если pull_request_template/.review-context.md отсутствует, остановись и не делай review.

## Зачем сделана задача

- Какая бизнес-проблема или пользовательский сценарий решается.
- Какой результат считается корректным.

## Дополнительный контекст (опционально)

- Что важно знать, но чего не видно из diff и из блока `Зачем`.
- Что легко неверно понять без короткого пояснения.

## Особые риски или акценты для review (опционально)

- Заполняй только если есть нетривиальный риск, скрытая зависимость или место, которое легко прочитать неправильно.
- Этот блок не ограничивает review и не сужает scope проверки.

## Что уже проверено вручную (опционально)

- Какие ручные сценарии уже прогнаны, если это полезно знать.
- Если отдельно ничего не проверялось, секцию можно удалить.

## Ограничения и компромиссы (опционально)

- Какие компромиссы приняты.
- Какие известные ограничения пока оставлены.

## Дополнительные настройки для агента (опционально)

- Не запускать локальную сборку / тесты, полагаться на CI/CD.
- Не сужать review до перечисленных мест, если не сказано явно.
- Нужный формат ответа: сначала findings, отсортированные по важности потом короткий блок Checks
- Блок findings пиши по уровням High, Medium, Low. Сам текст пиши на русском языке
- Ошибки освещай с 1-2 конкретным примером, типа "Было: при любой ошибки был статус 500, теперь при любой ошибке 
  статус 400, это значит что часть честных ошибок со статусом 500 некорректно превращаются в ошибки статус 400
